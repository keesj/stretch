Pose Capture Tool

  • 1) Pick a video (or photo) of ONE exercise — full body in frame, camera on a tripod, hold the pose for a few seconds.
  • 2) Type the animation id (e.g. downward-dog) and click Capture. It samples frames, detects the skeleton, and averages the joints.
  • 3) Check the skeleton overlay on the right, then Download JSON and save it as src/data/poses/<id>.json.
  • 4) Repeat per exercise, then run node scripts/pose-to-figures.mjs.
