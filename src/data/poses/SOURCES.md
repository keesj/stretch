# Pose capture sources

Keypoint captures in this directory were generated by running the pose-tool
pipeline (MediaPipe PoseLandmarker, same model and options as `pose-tool.html`)
headlessly on the source photos below, instead of filming new clips.

- `upward-salute` — Flickr via Openverse — Urdhva Hastasana (CC BY-NC)
- `toe-touch` — Wikimedia Commons — File:3Uttanasana.JPG (CC BY-SA 3.0)
- `lunge` — Wikimedia Commons — File:Āñjaneyāsana, Julija Zora Mazover, 2023.jpg (CC BY-SA 4.0)
- `upward-dog` — Wikimedia Commons — File:Upward-facing dog pose.jpg (CC BY-SA 3.0)
- `childs-pose` — Flickr via Openverse — Child's Pose | Balasana (CC BY-SA)
- `downward-dog` — Wikimedia Commons — File:5adho mukha shvanasana.JPG (CC BY-SA 3.0)
- `wide-leg-bend` — Flickr via Openverse — Wide-Legged Forward Fold (CC BY-NC-SA). Note: the figure's splayed legs are hand-drawn — a single photo capture can't resolve the wide stance (MediaPipe finds only one leg in this fold), so only the torso/head/arms proportions are photo-informed.
- `seated-shin` — Pexels photo 6926037 (Pexels license)
- `wall-calf` — Wikimedia Commons — File:The Calf Stretch 110402-A-XD329-017.jpg (Public domain, US Army)
- `soleus` — Flickr via Openverse — Step Right Up for a Great Stretch (CC BY-NC-SA)
